## 视觉对比

参考图的可取部分是紧凑标题、清晰分区、语义色、稳定底栏和高信息密度。新原型没有照搬工时产品内容，而是把这些原则应用到库存和批次任务：

- 一级导航从四项减为“今日 / 库存 / 设置”，扫描回到字段内辅助动作。
- 首页先展示今天要处理的事项，不放营销式大卡片。
- 新增采用全宽表单段落和固定保存动作，不使用卡片套卡片。
- 高频的“减少 1”“补货新批次”直接可见；危险操作收进更多菜单。
- 识别页面只显示用户需要的清晰度、字段进度和退出路径；诊断指标不进入普通模式。

## 交互证据

已通过浏览器按真实点击顺序验证：

1. 今日 -> 库存 -> 新增 -> 手动编辑 -> 整包装识别 -> 部分结果核对 -> 识别依据 -> 返回核对 -> 采用 -> 返回原编辑器。
2. 核对页商品名和条码可编辑；查看依据后修改值仍保留。
3. 日期识别失败可返回原编辑器，或勾选“暂时不知道日期”保存为“日期待补”，不会写成永不过期。
4. 名称、数量、日期三个错误可一次显示，并聚焦第一个错误；修正后可保存。
5. 库存筛选在底部面板完成，不发生横向标签截断。
6. 已知条码命中多个商品时，未选择前补货按钮禁用；选择后才进入独立新批次。
7. 提醒设置切换为固定模式后，未保存返回受到保护；保存后回到设置。
8. 日期专拍只显示日期状态，不再错误展示名称和条码已识别；读不清时可直接返回填写。
