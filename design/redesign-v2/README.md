# 食期管家 V2 可点击原型

直接打开 `index.html`，或在仓库根目录启动静态文件服务器后访问：

`http://127.0.0.1:8771/design/redesign-v2/index.html`

## 可走通流程

1. 总览 -> 扫描添加。
2. 自动模式先得到商品名和条码。
3. 核对部分结果，确认页会把缺失日期置顶。
4. 点击日期字段进入日期特写。
5. 日期稳定后核对全部结果并确认补货。
6. 商品详情显示独立新批次。
7. 库存页可直接减少 1 或补货。
8. 设置页包含提醒、JSON、Excel、备份和离线模型状态。

## 边界

- 这是信息架构和视觉交互原型，不是 Android 功能实现。
- 原型使用用户失败视频中提取的真实相机画面。
- 模拟日期只用于演示页面状态切换，不代表该视频已经通过真实 OCR。
- Android 实现必须继续遵守 OCR 结果经用户确认后才保存的规则。
