# 食期管家 V2 系统原型

直接打开 `index.html`，或在仓库根目录启动静态文件服务器后访问：

`http://127.0.0.1:8771/design/redesign-v2/index.html`

## 关键设计

- 一级导航只保留“今日、库存、设置”；扫描不再占用导航位置。
- 点击“新增”直接进入手动编辑器，相机、条码和日期识别都是辅助入口。
- 识别不完整也可以进入核对并继续填写，商品名和条码可直接修改。
- 查看识别依据后返回核对页，原编辑器草稿保持不变。
- 库存保留可见的减少 1 和补货；补货始终创建独立新批次。
- 条码命中多个本机商品时必须明确选择，系统不默认一对一。
- JSON、Excel 和备份页面展示筛选、预览、错误行、校验与回滚状态。

## 可走通流程

1. 今日/库存 -> 新增 -> 手动填写 -> 保存。
2. 新增 -> 拍包装 -> 部分识别 -> 核对并编辑 -> 采用 -> 回到原表单。
3. 库存 -> 商品详情 -> 减少 1/撤销 -> 补货新批次。
4. 库存 -> 扫码查找 -> 多商品明确选择 -> 补货。
5. 设置 -> 智能/固定提醒、JSON、Excel、备份恢复、识别调试。

## 边界

- 这是信息架构和视觉交互原型，不是真实 Android 数据或 OCR 实现。
- 相机画面来自已有失败样本，仅用于呈现交互状态。
- 原型中的识别结果是状态模拟，不代表用户视频已经通过字段级 OCR 验收。
- Android 实现仍必须执行自动测试、视频回放、模拟器/真机视觉和覆盖安装保数。

视觉和交互验收记录见 [design-qa.md](design-qa.md)，当前结论为 `passed`。
