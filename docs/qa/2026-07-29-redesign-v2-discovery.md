## 设计修复

1. 产品域扩展到食品、药品、个护和家庭耗材。
2. 识别拆为定位、转录、解析、字段提升四层。
3. CameraX 和 OCR 只保留最新待处理帧。
4. 日期 ROI 拥有独立识别预算。
5. 全图快检测与局部慢识别分离。
6. 录屏回放遮罩旧 UI 文案，真实相机直接处理原始帧。
7. 单一状态机驱动页面，不允许互相矛盾的状态。
