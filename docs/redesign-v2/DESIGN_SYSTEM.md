# 食期管家 V2 交互与视觉规范

状态：原型基线  
日期：2026-08-31

## 1. 目标

界面服务于重复、快速、可纠错的本地库存操作。视觉上参考用户提供的中文效率工具：小型页标题、清楚分组、紧凑列表、明确状态和有限主色；不复制其工时业务内容。

## 2. 页面类型

### 一级页

- 今日、库存、设置。
- 固定系统栏、页标题和三项底部导航。
- 今日和库存右上角使用相同“新增”按钮。
- 首屏必须看见页面目的、主要操作和至少一条真实内容。

### 任务页

- 商品详情、编辑器、相机、核对、补货、条码选择、导入预览、设置子页。
- 隐藏底部导航，显示返回、任务标题和固定底部主操作。
- 中间内容独立滚动，底部操作不得遮住最后一项。

### 临时选择

- 库存筛选、日期选择、危险操作确认使用底部页或对话框。
- 保持来源页面可辨认，不把筛选做成横向溢出的标签长条。

## 3. 设计令牌

### 色彩

| 用途 | 值 | 说明 |
| --- | --- | --- |
| 页面背景 | `#F4F6F8` | 中性浅灰 |
| 内容背景 | `#FFFFFF` | 列表和表单区 |
| 主文字 | `#17212B` | 标题与正文 |
| 次文字 | `#63758A` | 说明和元数据 |
| 分隔线 | `#D8E0E7` | 列表、输入和区块 |
| 主操作 | `#1F64E5` | 新增、保存、采用 |
| 正常/成功 | `#14825D` | 正常库存、校验通过 |
| 待核对/临期 | `#A76600` | 日期缺失、临期 |
| 异常/过期 | `#C83D35` | 无效、过期、危险 |

蓝色只表示操作和选择；状态必须同时显示文字，不能只依赖颜色。

### 字体

- 字体栈：`Noto Sans SC`、`Microsoft YaHei UI`、`Microsoft YaHei`、系统无衬线。
- 一级标题：24sp/700；任务标题：21sp/700。
- 区块标题：18sp/700；列表名称：16sp/700；正文：16sp/400。
- 元数据和说明：13 至 14sp，正常字重。
- 字距固定为 0，不随视口宽度缩放字号。

### 间距与形状

- 基础间距：4dp；常用间距：8、12、16、20、24dp。
- 页面水平边距：16dp。
- 列表行最小高度：64dp；高频操作行 78 至 88dp。
- 触控目标：至少 48x48dp。
- 卡片只用于可重复的商品、批次和真正需要边界的工具，圆角不超过 8dp。
- 页面区块使用全宽色带或分隔线，不把整个表单节做成漂浮卡片。
- 不使用渐变、装饰光球、嵌套卡片或大面积阴影。

## 4. 核心组件

### 顶栏

- 左侧返回仅用于任务页。
- 标题最多一行，过长省略；副标题说明当前上下文。
- 右侧只放一个高频动作或一个更多菜单，不堆多个文字按钮。

### 底部导航

- 仅今日、库存、设置三个目的地。
- 图标与文字同时显示；选中项使用主色。
- 扫描、趋势、数据导入都不是一级目的地。

### 商品行

- 左：稳定的类别标记或本地商品图。
- 中：名称、批次数量、最早到期与总剩余量。
- 右：48dp 减量图标和“补货”按钮。
- 长中文名称最多两行，操作区尺寸固定，不能挤压到不可读。

### 批次行

- 显示可区分的 UUID 尾号、最终日期、剩余/总量、保存与开封状态。
- 高频“减少 1”直接可见；编辑和更多操作次级。
- 备注和开封后建议日期不可隐藏在另一个页面。

### 表单

- 标签在输入框上方，必填/选填直接写明。
- 错误显示在字段下方，并自动滚动聚焦到第一个错误。
- 日期两种模式用分段控件；切换不清空另一模式草稿。
- 相机和条码使用字段右侧图标按钮并提供可读辅助标签。
- 底部固定一个保存动作；保存中、失败和成功都有明确状态。

### 相机

- 预览全屏，不放在装饰卡片。
- 顶部只显示返回、任务名、对焦提示和手电筒。
- 框的颜色区分“已形成字段”和“仅可能有信息”，标签使用用户语言。
- 底部仅显示当前状态、名称/条码/日期进度和一个主操作。
- 普通模式不显示 FPS、队列、耗时、模型名、ROI 或候选数量。

### 识别核对

- 冲突和缺失字段置顶。
- 推荐值使用真实输入控件，用户可直接改一个字。
- 关键帧默认收起，通过“查看依据”进入独立页面；返回保持核对状态。
- 主操作是“采用并继续填写”，不是直接保存库存。

### 状态与反馈

- 字段错误：字段内红色文字，不只使用 Toast。
- 短时成功/撤销：底部 Snackbar，6 秒内可撤销。
- 删除和覆盖：对话框写明对象、影响范围和不可恢复部分。
- 长任务：页面内显示当前阶段、剩余动作和安全退出，不使用无限转圈。
- 空库：只给一个“新增”入口，手动填写和相机辅助在编辑器内选择。

## 5. 响应式规则

### 360x640

- 标题、主操作和一条内容必须同屏。
- 表单固定底部按钮高度 52dp；内容区预留至少 76dp。
- 双列字段在空间不足时改成单列。
- 筛选使用两列底部页，不使用水平滚动。

### 360x800

- 今日页显示摘要、三条优先事项和最近操作。
- 编辑器首屏显示商品字段与日期模式。
- 相机预览仍占主要空间，底部面板不超过约 34% 屏高。

### 高密度输出

- 720x1280 对应 360x640 的 2x 密度。
- 1080x2400 对应 360x800 的 3x 密度。
- 密度变化不改变 CSS 布局、字号和触控逻辑，只提高像素清晰度。

## 6. 无障碍

- 每个交互目标至少 48dp。
- 小正文和背景对比度至少 4.5:1，大文字与图形至少 3:1。
- 图标按钮提供 `contentDescription`；装饰图标不重复朗读。
- 错误、成功、临期和过期同时使用文字，不依赖颜色。
- 删除不能只有滑动手势；所有功能都能通过可见控件完成。
- TalkBack 阅读顺序遵循视觉顺序：页面标题、状态、字段、说明、操作。
